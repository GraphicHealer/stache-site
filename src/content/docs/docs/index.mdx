**"Where is my stuff?"** — snap a photo, drop the thing in a bin, scan the bin's QR label. No names required, no categories, no forms. Finding it later is search, photo similarity, or just looking inside the bin from your couch.

Everything runs in a single container — no database service, no external anything. Works offline, works on phones, works on Zebra handhelds with a scan trigger.

## Pick your install

Stache is a standalone app — one container, no database service, no required extras. **[Three ways to run it](/docs/getting-started/)**, pick one:

- **[Docker](/docs/getting-started/docker/)** — the standard route; works on any Docker host.
- **[Home Assistant](/docs/getting-started/home-assistant/)** — easiest *if you already run Home Assistant*: one click from the add-on store.
- **[Unraid](/docs/getting-started/unraid/)** — single appdata folder, Community Applications template.

Then head to **[Your first bin](/docs/getting-started/first-steps/)** to print labels and file your first item in about two minutes.
