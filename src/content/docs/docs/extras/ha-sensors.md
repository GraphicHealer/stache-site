---
title: Home Assistant sensors
description: Bring Stache inventory counts into Home Assistant dashboards and automations.
---

The [Stache HACS integration](https://github.com/GraphicHealer/stache-ha) makes selected inventory information available as Home Assistant sensors. You can use the sensors in dashboards, automations, and notifications.

## Install the integration

[![Add Stache integration via HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=GraphicHealer&repository=stache-ha&category=integration)

1. Select the badge above, or add `https://github.com/GraphicHealer/stache-ha` to HACS as a custom repository with the category **Integration**.
2. Install **Stache** from HACS.
3. Restart Home Assistant.
4. Open **Settings → Devices & Services → Add Integration** and select **Stache**.

The integration requires Home Assistant **2025.1** or newer.

## Connect it to Stache

The integration needs the sensor URL generated by Stache:

1. In Stache, open **Settings → Out reminders**.
2. Enable the feature if it is currently off.
3. Select **Copy sensor URL**.
4. Paste the complete URL into the Home Assistant setup dialog.

The integration extracts the Stache host and token from the URL. If you prefer, you can enter the Stache URL and webhook token as separate fields.

## Available sensors

| Sensor | State | Attributes |
|---|---|---|
| Items out | Count of items marked Out or Lent | Item names, area paths, and days out |
| Unaccounted | Count of items nobody has seen lately | — |
| Low stock | Count of items at or below their restock threshold | Names, quantity, and threshold |
| Warranty expiring | Count of warranties ending within 30 days | Names and end dates |

The integration polls Stache every 2 minutes by default. Change the interval in the integration's **Configure** options; supported values are 30–3600 seconds.

All shared household items are included. Private items are never exposed. If the stored token is rejected, Home Assistant creates a repair issue asking you to provide a fresh one.

## Use the endpoints without HACS

Stache also displays a ready-made REST sensor URL and a digest trigger URL in **Settings**. You can use these directly in your own Home Assistant REST sensors or automations without installing the HACS integration.
